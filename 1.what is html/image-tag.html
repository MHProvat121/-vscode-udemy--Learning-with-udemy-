How importing a "image file", in a "html file" works

  1. First ,locate the folder of "index.html" / your working html file,
    • ex: my "image-tag.html" working file is in "Learning With udemy" folder
  2. Second, ensure if your image.png is in the exact same folder or not.
    • If it is in the same folder, you can directly use the image name with extension in src attribute.
    • If it is in a different folder, you need to provide the relative path from your working file to the image file.
      • Example: my "image-tag.html" remains in "Learning with udem" folder
      • but my "forloop.png" is in "learning with udemy/images" folder
      • So, I need to go one level up from "learning with udemy" folder to access "images" folder.
      • Thus, the relative path becomes "..\images\forloop.png"
